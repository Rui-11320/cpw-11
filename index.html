TechNova

Neste clube, o nosso objetivo é ensinar os alunos interessados sobre programação e tecnologia.
Acreditamos que, ao ensinar os jovens a criar e a programar desde cedo, lhes damos ferramentas
essenciais para o futuro. Isto promove o pensamento crítico, a criatividade e a capacidade de resolver
problemas em equipa.

Atividades

Como atividade, gostaria de organizar uma "Game Jam" escolar, onde os alunos se dividissem
em equipas para criar pequenos videojogos do zero ao longo de um mês, estimulando a programação
e o design de forma criativa.

Áreas que o clube explora.

  • Cibersegurança
  • Inteligência Artificial

Atividades que o clube realiza.

Sessão de criação de um site

Nesta sessão vamos aprender a organizar uma página web, utilizando HTML e CSS para criar um site simples.

Materiais necessários
